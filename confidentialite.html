Politique de confidentialité

Dernière mise à jour : 20 novembre 2026

Cette politique concerne le site vinxlabs.fr et le logiciel Nilo (« Nilo Project » sur le Microsoft Store). Responsable du traitement : Vincent ROMEO, VinX Labs, 2 boulevard du 14 Juillet, 13500 Martigues — contact@vinxlabs.fr.

1. En bref

Vos projets, tâches et fichiers restent sur votre ordinateur, dans le dossier que vous choisissez (votre « vault »). VinX Labs n'y a jamais accès : Nilo n'a ni compte, ni serveur, ni publicité, ni mesure d'audience.

2. Ce que Nilo envoie sur Internet

Nilo ne se connecte à Internet que dans ces cas :

  • Licence Entreprise (si vous l'achetez) : à l'activation puis lors de vérifications périodiques, Nilo envoie à Polar la clé de licence, un nom de poste (« Nilo — Windows ») et, comme toute connexion, votre adresse IP. L'achat lui-même (nom, e-mail, pays, paiement) est traité par Polar, revendeur officiel, selon sa politique de confidentialité.
  • Mises à jour : la version Microsoft Store est mise à jour par le Microsoft Store ; la version téléchargée sur ce site interroge GitHub (adresse IP, version installée).
  • Retours et signalements, uniquement si vous le décidez : un e-mail à contact@vinxlabs.fr (préparé par Nilo, que vous relisez avant l'envoi ; il contient la version de Nilo, celle de Windows et le détail technique de l'erreur) ou le formulaire Google Forms.

3. Le site vinxlabs.fr

L'éditeur ne dépose aucun cookie ni outil de suivi sur ce site, qui ne charge aucune ressource tierce (les polices sont hébergées sur le site). Il est hébergé par GitHub Pages, qui reçoit votre adresse IP pour afficher les pages. Seul le choix du thème clair ou sombre est mémorisé dans le stockage local de votre navigateur ; il n'est jamais transmis. Les liens de téléchargement mènent vers GitHub, qui applique sa propre politique de confidentialité.

4. Données que VinX Labs conserve

Pour les acheteurs de la licence Entreprise : les informations de commande visibles dans Polar (nom, e-mail, pays, clé), afin de gérer les licences, le support et les remboursements, pendant la durée légale de conservation des données de facturation (10 ans). Pour les personnes qui écrivent au support : leurs e-mails, le temps de traiter la demande. Ces données ne sont ni vendues, ni utilisées pour de la prospection commerciale.

Bases légales : l'exécution du contrat (licence, support), nos obligations légales (facturation) et, pour la vérification des mises à jour, l'intérêt légitime de l'éditeur à distribuer des versions à jour.

5. Transferts hors Union européenne

Polar et GitHub sont des prestataires situés hors de l'Union européenne : les données qui leur sont confiées (commande et licence pour Polar, hébergement du site, téléchargements et mises à jour pour GitHub) peuvent donc être traitées hors de l'Union européenne, selon leurs propres politiques.

6. Vos droits

Vous pouvez demander l'accès, la rectification ou l'effacement de vos données, ou vous opposer à leur traitement, en écrivant à contact@vinxlabs.fr. Vous pouvez aussi saisir la CNIL.

7. Modifications

Cette page peut évoluer avec Nilo ; la date en haut indique la dernière mise à jour.
