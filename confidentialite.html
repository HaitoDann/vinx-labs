Politique de confidentialité

Dernière mise à jour : 28 octobre 2026

Cette politique concerne le site vinxlabs.fr et le logiciel Nilo (« Nilo Project » sur le Microsoft Store). Responsable du traitement : Vincent ROMEO, VinX Labs, 2 boulevard du 14 Juillet, 13500 Martigues — contact@vinxlabs.fr.

1. En bref

Vos projets, tâches et fichiers restent sur votre ordinateur, dans le dossier que vous choisissez (votre « vault »). VinX Labs n'y a jamais accès : Nilo n'a ni compte, ni serveur, ni publicité, ni mesure d'audience.

2. Ce que Nilo envoie sur Internet

Nilo ne se connecte à Internet que dans ces cas :

  • Licence Entreprise (si vous l'achetez) : à l'activation puis lors de vérifications périodiques, Nilo envoie à Lemon Squeezy la clé de licence, un nom de poste (« Nilo — Windows ») et, comme toute connexion, votre adresse IP. L'achat lui-même (nom, e-mail, pays, paiement) est traité par Lemon Squeezy, revendeur officiel, selon sa politique de confidentialité.
  • Mises à jour : la version Microsoft Store est mise à jour par le Microsoft Store ; la version téléchargée sur ce site interroge GitHub (adresse IP, version installée).
  • Retours et signalements, uniquement si vous le décidez : un e-mail à contact@vinxlabs.fr (préparé par Nilo, que vous relisez avant l'envoi ; il contient la version de Nilo, celle de Windows et le détail technique de l'erreur) ou le formulaire Google Forms.

3. Le site vinxlabs.fr

Le site ne dépose aucun cookie et n'utilise aucun outil de suivi. Il est hébergé par GitHub Pages, qui reçoit votre adresse IP pour afficher les pages. Les polices sont chargées depuis Google Fonts, et la page Nilo interroge GitHub pour afficher le numéro de la dernière version : ces services reçoivent aussi votre adresse IP.

4. Données que VinX Labs conserve

Pour les acheteurs de la licence Entreprise : les informations de commande visibles dans Lemon Squeezy (nom, e-mail, pays, clé), afin de gérer les licences, le support et les remboursements, pendant la durée légale de conservation des données de facturation (10 ans). Pour les personnes qui écrivent au support : leurs e-mails, le temps de traiter la demande. Ces données ne sont ni vendues, ni utilisées pour de la prospection commerciale.

Base légale : l'exécution du contrat (licence, support) et nos obligations légales (facturation).

5. Vos droits

Vous pouvez demander l'accès, la rectification ou l'effacement de vos données, ou vous opposer à leur traitement, en écrivant à contact@vinxlabs.fr. Vous pouvez aussi saisir la CNIL.

6. Modifications

Cette page peut évoluer avec Nilo ; la date en haut indique la dernière mise à jour.
